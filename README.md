# STM32-LCD16x2-Interfacing

A beginner-friendly guide to interfacing a 16x2 character LCD with an STM32 microcontroller using a custom LCD library.

# Acknowledgement

The LCD library used in this project was originally provided by **GARD academy**, where I was a student.

I would like to acknowledge GARD as the original source of this library. The library is included here for educational and project demonstration purposes.
